# TRJ-InfoRecon

## Açıklama
TRJ-InfoRecon, terminal tabanlı güçlü ve kolay kullanımlı bir bilgi toplama aracıdır.  
Bir domain girerek aşağıdaki bilgilere hızlıca ulaşabilirsiniz:

- Whois sorgusu  
- DNS kayıtları (A, MX, NS)  
- IP adresi çözümleme  
- Subdomain taraması (crt.sh API ile)
